A SEO Content Generation Application with the ability to generate both text and images, including real-time status updates.

This project consists of a React frontend and a FastAPI backend.
The user can enter a keyword, select a domain, and the system automatically generates SEO-optimized content along with an image and displays it to the user.
The content generation process is also shown in real time.

Technologies Used
React
React Hooks (useState, useEffect, useRef)
Fetch API
Custom CSS
react-icons
